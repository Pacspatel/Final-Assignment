# HTML and CSS Projects

This repository contains the HTML and CSS exercises and projects I completed during my course.

# 1. HTML Exercises
I learned how to create webpages using HTML. I practiced using headings, paragraphs, links, images, lists, and other HTML elements.

# 2. CSS Exercises
I learned how to use CSS to change the look of my webpages. I practiced changing colors, fonts, spacing, borders, backgrounds, and sizes.

# 3. CSS Effects
I created CSS effects using hover, transitions, and transformations. I learned how CSS can make a webpage more interactive.

# 4. About Page
I created an About page with a navigation bar. I also practiced using links to move to different sections of the page.

# 5. One-Page Website
I created a one-page website using HTML and an external CSS file. I practiced using fonts, colors, spacing, and form elements.

# 6. Bootstrap Exercises
I learned how to use Bootstrap to create responsive webpages. I practiced using the Bootstrap grid system, buttons, cards, and other Bootstrap features.

# 7. Bootstrap Footer
I created a footer using the Bootstrap grid system. I added different sections for contact information, social media, and copyright information.

# 8. Bootstrap Album
I created an album webpage using Bootstrap. I practiced using cards, images, descriptions, and the Bootstrap layout.

# 9. Recipe Website
I created a simple recipe website using HTML and CSS. I added recipes, a navigation bar, images, fonts, and different CSS styles.

# 10. Final Portfolio Website
For my final project, I created a student portfolio website using HTML and CSS.
My portfolio includes:
* Home
* About
* GitHub
* Contact
* Navigation bar
* Background video
* Images
* CSS hover effects
* CSS animations

I also published my portfolio website using GitHub Pages.

## 11. What I Learned
During this course, I learned how to create and style webpages using HTML and CSS. I also learned how to use GitHub to save my projects and publish a website online.
